# Loops

## For loop

THP loops are similar to PHP's `foreach`. There is no equivalent to PHP's `for`.

Braces are required.

### Loop over values

<Code thpcode={`
val numbers = [0, 1, 2, 3]

for number in numbers {
    print(number)
}
`} />

<Code thpcode={`
val dict = .{
    apple: 10,
    banana: 7,
    cherries: 3,
}

for value in dict {
    print("{value}")
}
`} />

### Loop over keys and values

<Code thpcode={`
val numbers = [0, 1, 2, 3]

for index, number in numbers {
    print("{index} : {number}")
}
`} />

<Code thpcode={`
val dict = .{
    apple: 10,
    banana: 7,
    cherries: 3,
}

for key, value in dict {
    print("{key} => {value}")
}
`} />

## While loop

<Code thpcode={`
val colors = ["red", "green", "blue"]
var index = 0

while index < colors.size() {
    print("{colors[index]}")
    index += 1
}
`} />
